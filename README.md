## 📥 How to Install (Android)

Because this app is self-published and not hosted on the Google Play Store, Android will flags it as an "Unknown Source." Follow these simple steps to install it safely:

1. Go to the **Releases** section on the right side of this GitHub page.
2. Download the **`app-release.apk`** file onto your Android device.
3. Open the downloaded file. 
4. If prompted to allow installations from your browser/GitHub, tap **Settings** and toggle on **"Allow from this source"**.
5. If Google Play Protect shows a warning, tap **More details** and then select **Install anyway**.
